# Pratham Kapadia — Web Technologies Portfolio

A responsive portfolio made with plain HTML, CSS and JavaScript. No framework, build step, or package installation is needed.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design, original CSS graphics, animations and colour palettes
- `script.js` — mobile navigation, scroll reveals and theme switching
- `assets/profile.png` — the profile photo supplied for this portfolio

## Colour themes
The default is **Dark Neon** (cyan, violet and pink). Use the four colour dots in the header to switch between:
1. Dark Neon — cyan / violet / pink
2. Emerald Gold — green / gold / mint
3. Sunset — orange / coral / violet
4. Rose Violet — pink / purple / sky blue

The selected theme is remembered in the visitor's browser.

## Run locally
Open `index.html` in a browser. No installation is required.

## Publish with GitHub Pages
1. Create a repository on GitHub, for example `web-technologies-portfolio`.
2. Upload the contents of this folder to the repository root. Keep `index.html`, `style.css`, `script.js`, and the `assets` folder together.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait for deployment. GitHub Pages will show the live website address.

## Safety
- Never upload passwords, API keys, personal access tokens, private phone numbers or private addresses.
- A public repository and website can be viewed by anyone.
- Only publish the profile photo and contact details you are comfortable sharing publicly.
